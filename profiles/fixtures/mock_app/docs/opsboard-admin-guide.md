# email address

The email address identifies a person signing in or receiving notifications.

# password

The password authenticates a user session and must never be logged.

# incident status

Incident status filters dashboard records by operational state.

# service owner

Service owner identifies the team or person responsible for a service.

# alert email

Alert email receives workspace notifications.

# maintenance window

Maintenance window describes the scheduled period for routine changes.

# retention days

Retention days controls how long operational records are retained.

# user email

User email is the destination address for a user invitation.

# access role

Access role controls permissions assigned to a user.

# date range

Date range limits report output by time period.

# export format

Export format selects the report file type.

# item name

Item name identifies a managed list item. The web UI accepts names from 1 to 10 characters.

# service port

Service port records the TCP or UDP port number associated with a managed item.

# enabled

Enabled controls whether a managed item is active. Items can be activated, deactivated, and removed.
