# wan status

WAN status indicates whether the router reports its external network connection as connected or disconnected.

# internet uptime

Internet uptime is the duration of the current WAN connectivity session.

# ip address

IP address is the network address displayed for a WAN, LAN, or client interface. Operators are responsible for protecting saved configuration repositories.

# ssid name

SSID name is the visible Wi-Fi network name broadcast by a wireless interface.

# ssid switch

SSID switch indicates whether a wireless network is enabled or disabled.

# wlan channel

WLAN channel is the radio channel used by a 2.4 GHz or 5 GHz wireless interface.

# encryption type

Encryption type describes the Wi-Fi security mode used by an SSID.

# voip status

VoIP status indicates registration state for configured phone lines.

# device type

Device type is the router model shown in the management interface.

# software version

Software version is the router firmware version shown in device information.

# hardware version

Hardware version is the hardware revision shown in device information.

# system uptime

System uptime is the duration since the router last started.

# access devices

Access devices are client devices shown in topology or LAN status views. Device names, IP addresses, and MAC addresses may appear in configuration snapshots; operators are responsible for repository access controls.
