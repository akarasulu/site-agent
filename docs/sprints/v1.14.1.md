# Sprint v1.14.1

Date: 2026-06-16

## Goal

Reduce generated explorer noise by rendering browser-facing artifacts as
human-readable pages and collapsing dense evidence by default.

## Delivered

* Added rendered HTML sidecars for generated Markdown docs and Postman
  collection/environment artifacts in the explorer artifact directory.
* Added browser redirects from raw Markdown, Postman, and OpenAPI artifact
  paths to the human-facing rendered pages.
* Preserved raw artifact downloads through `raw_href` links and `?raw=1`.
* Collapsed evidence by default in rendered Markdown evidence tables, MCP tool
  rows, and the Audit detail panel.
* Reused the explorer HTTP socket address so a freshly restarted server can
  bind to the requested port.

## Validation

```bash
python -m pytest tests/unit/test_explorer.py tests/unit/test_cli_flow.py::test_cli_fixture_flow
python -m py_compile site_agent/core/explorer.py site_agent/cli.py
git diff --check
```

Browser smoke validation against the regenerated ZTE explorer confirmed:

* `http://127.0.0.1:8765/index.html` served successfully.
* MCP tab evidence rendered as collapsed `<details>` blocks by default.
* Audit detail evidence rendered as a collapsed `<details>` block by default.
* Browser-style requests for raw Markdown/Postman/OpenAPI artifact paths
  redirected to rendered helper pages.

## Notes

The explorer now distinguishes human browsing from machine consumption. A user
clicking around the explorer sees rendered documentation and collapsed
evidence, while automation and import workflows can still download raw JSON,
YAML, or Markdown artifacts.
