# Sprint v1.14.0

Date: 2026-06-16

## Goal

Make the generated explorer easier for API consumers to understand by turning
the default view into a documentation portal while preserving the dense
evidence/audit view for reviewers.

## Delivered

* Added generated quickstart, Python API, MCP, and Ansible Markdown docs to the
  documentation bundle.
* Added explorer tabs for Overview, API, Python, MCP, Ansible, Postman, and
  Audit.
* Added `swagger.html` and copied generated OpenAPI/Postman/Markdown artifacts
  into `output/<profile>/explorer/artifacts/`.
* Made `site-agent explorer build` and `site-agent explorer serve` refresh the
  generated documentation bundle before publishing the explorer.
* Added generated docs and Postman files to profile knowledge packages.

## Notes

The explorer now opens on the user-consumption path: start the local API
bridge, open Swagger UI, import Postman files, or follow the Python/MCP/Ansible
docs. The original UI evidence browser remains available under the Audit tab
for reviewers who need raw page, field, adapter, and evidence context.
